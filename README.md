# Business Model Canvas (Thai)

Responsive 9-block Business Model Canvas web app. Enter a product or service in Value Proposition, generate 5–10 editable bullet points per block, save locally, export JSON, and print to PDF.

**Important:** Suggestions are template-based, not AI-generated market research.

## GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Visit `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/` once published.

No build tools or API keys required.
